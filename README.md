#  Light Cycle

Tron esintili, 2 kişilik local ışık motosikleti (light cycle) oyunu. Arkanda parlayan bir iz bırakırsın — kendi izine ya da rakibinin izine çarpan kaybeder.

**Oyna:** [Canlı link](https://emirhankrcbn.github.io/light-cycles/) *(GitHub Pages aktif edince çalışır)*

## Kontroller
| | Yön |
|---|---|
| Oyuncu 1 (Mavi) | `W A S D` |
| Oyuncu 2 (Pembe) | Ok tuşları |

## Özellikler
- Tur bazlı skor takibi, geri sayımlı başlangıç
- Grid tabanlı hareket, artan hız hissi
- Web Audio API ile ses efektleri (dönüş, çarpışma, kazanma)
- Harici bağımlılık yok — tek HTML dosyası

## Teknoloji
Vanilla JavaScript + HTML5 Canvas
